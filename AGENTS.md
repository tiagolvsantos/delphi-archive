## Project

`delphi-archive` is the central archive for investment research, quantitative studies, and market analysis supporting the Cerberus ecosystem. It is a data archive, not an application: there is no build, test, or runtime to maintain. See [README.md](README.md) for contents.

```
delphi-archive/
├── stock_reports/   # Per-ticker equity research PDFs, generated by Cerberus Workbench
└── studies/         # Quantitative research studies, organized by domain
```

## Principles

- This is an append-mostly archive. Do not delete, rename, or overwrite existing `stock_reports/` or `studies/` content unless explicitly asked to.
- Preserve the `report_<TICKER>_<TIMESTAMP>.pdf` naming convention for stock reports; do not regenerate or renumber historical reports.
- Keep new studies filed under the existing domain folders (`alternative_data/`, `credit/`, `crypto/`, `fundamentals/`, `macro/`, `market_internals/`, `options/`, `sentiment/`, `space/`, `volatility/`); create a new domain folder only when a study genuinely fits none of them.
- Update `README.md`'s contents table when adding a new study or a materially new report category.
